## Overview
This Personal Portfolio is a modern, responsive web application built using React. It serves as a showcase for your skills, projects, and experiences, making it an essential tool for job applications and personal branding. The data displayed in the portfolio is dynamically linked to a JSON file, allowing for easy updates and customization.

## Features
- **Dynamic Data Loading**: The portfolio pulls data from a JSON file, making it easy to update your information without modifying the code.
- **Responsive Design**: The layout is fully responsive, ensuring a seamless experience on both desktop and mobile devices.
- **Customizable Sections**: Easily modify sections such as About, Resume, Portfolio, Testimonials, and Contact to reflect your personal brand.
- **Dark Mode Support**: A toggle feature allows users to switch between light and dark themes for a personalized viewing experience.
- **Smooth Scrolling**: Navigation links provide a smooth scrolling effect, enhancing user experience.
- **Filterable Portfolio**: Users can filter projects by category, making it easy to showcase relevant work.

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/en/download/) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ChillWithKanwal/CodeAlpha_Build_Your_Own_Portfolio_Site.git
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repo-name
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Application
To start the development server, run:
```bash
npm start
```
This will launch the application in your default web browser at `http://localhost:3000`.

### Customizing Your Portfolio
1. Open the `public/resumeData.json` file to update your personal information, including your name, occupation, skills, and project details.
2. Replace images in the `public/images/portfolio` directory with your own project images.
3. Modify the styles in `src/App.css` and `src/theme.css` to match your personal branding.

### Building for Production
Once you are satisfied with your portfolio, you can create a production build by running:
```bash
npm run build
```
This will generate a `build` folder containing the optimized application for deployment.

## Deployment
You can host your portfolio online using platforms like [Netlify](https://www.netlify.com/) or [Vercel](https://vercel.com/). Simply drag and drop the contents of the `build` folder into the designated upload space on these platforms.
